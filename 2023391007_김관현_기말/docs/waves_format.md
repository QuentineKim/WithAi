# 웨이브 데이터 파일 형식 (`waves.txt`)

`project/src/waves.txt`는 MVC 겔러그의 편대 적 출현을 데이터로 정의하는 텍스트 파일입니다.
파서(`project/src/models/WaveParser.lua`)는 파일 입출력 없이 **문자열만 입력받아** 줄 단위로 검증합니다.
파일 읽기는 `project/src/main.lua`에서만 `love.filesystem.read("waves.txt")`로 수행합니다.

---

## 1. 줄 규칙

- 줄바꿈은 LF(`\n`)와 CRLF(`\r\n`)를 모두 허용합니다.
- 앞뒤 공백(스페이스, 탭)은 무시합니다.
- 빈 줄과 `#`으로 시작하는 주석 줄은 무시합니다. (인라인 주석은 지원하지 않습니다.)
- 그 외 모든 줄은 아래 두 명령어 중 하나와 **정확히** 일치해야 합니다.

### 1-1. 웨이브 헤더
```text
wave <id>
```
- `<id>`: 1 이상의 양의 정수 (`1`, `2`, `3`, ...)
- 같은 `<id>`를 중복 선언할 수 없습니다.
- 파일에 최소 1개 이상의 웨이브가 있어야 하며, 각 웨이브에는 최소 1기 이상의 적이 있어야 합니다.

### 1-2. 적 배치
```text
spawn <kind> <x> <y>
```
- 반드시 `wave <id>` 선언 이후에 나와야 합니다.
- `<kind>`: 적 종류 문자열 (영문자·숫자·밑줄 `[A-Za-z0-9_]+`, 예: `basic`, 향후 R3에서 `diver`, `tank` 등 확장)
- `<x>`, `<y>`: 0 이상의 숫자 (좌표, 정수 또는 소수 허용, `NaN`/`inf` 불가)
- 토큰 개수가 4개보다 적거나 많으면 오류입니다.

---

## 2. 예시

```text
# 1웨이브: 기본 2열 편대
wave 1
spawn basic 60 60
spawn basic 120 60
spawn basic 180 60

# 2웨이브: V자 편대
wave 2
spawn basic 120 60
spawn basic 180 110
spawn basic 240 60
```

---

## 3. 파서 반환 구조

`WaveParser.parse(text)`는 성공 시 아래와 같은 배열 테이블을 반환합니다.

```lua
{
  {
    id = 1,
    spawns = {
      { kind = "basic", x = 60, y = 60 },
      { kind = "basic", x = 120, y = 60 },
    },
  },
  ...
}
```

---

## 4. 오류 보고 규칙

잘못된 줄을 **조용히 건너뛰지 않고**, 즉시 `error()`로 실패를 보고합니다.
에러 메시지에는 반드시 **원인이 된 줄 번호**가 포함됩니다.

형식: `waves:<줄번호>: <사유>`

| 오류 유형 | 예시 입력 | 보고 방식 |
|---|---|---|
| 알 수 없는 명령어 / 오타 | `spwn basic 60 60` | 해당 줄 번호와 함께 에러 |
| 인자 부족 / 초과 | `spawn basic 60` / `spawn basic 60 60 extra` | 해당 줄 번호와 함께 에러 |
| 잘못된 웨이브 번호 | `wave 0` / `wave 1.5` / `wave abc` / 중복 `wave 1` | 해당 줄 번호와 함께 에러 |
| 잘못된 적 종류 / 좌표 | `spawn bad-kind 60 60` / `spawn basic abc 60` / `spawn basic -10 60` | 해당 줄 번호와 함께 에러 |
| `wave` 헤더 전 `spawn` | 파일 첫 줄에 `spawn basic 60 60` | 해당 줄 번호와 함께 에러 |
| 빈 웨이브 / 빈 파일 | 적 없이 다음 `wave` 또는 EOF 도달 | 해당 웨이브 헤더 줄(또는 1번 줄) 번호와 함께 에러 |
